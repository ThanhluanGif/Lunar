# C-002 — Chuyển Lunar API khỏi Vercel sang Render

status: todo
deps: none
implements: infra

## Scope

Chuyển đúng một production API origin: đóng gói Express thành backend-only container, khai báo
Render Web Service always-on tại Singapore, cấu hình frontend Vercel gọi API cross-origin và chuyển
GitHub OAuth callback sang Render. Giữ nguyên PostgreSQL/Supabase, endpoint contract và giao diện;
hoàn tất cấu hình CORS, proxy và cookie `SameSite=None; Secure` để đăng nhập vẫn hoạt động giữa
`https://lunar-zeta-ruddy.vercel.app` và backend mới. Không xóa Vercel Functions trước khi live
verification xanh để còn đường rollback.
